자주 묻는 질문
API 키가 없어도 사용할 수 있나요?

네. 키가 없으면 데모 데이터로 먼저 구조를 확인할 수 있습니다. 키를 넣으면 YouTube 공식 API를 사용합니다.

이 점수는 정확한 예측인가요?

정확한 예언이 아니라, 다음에 볼 후보를 빠르게 줄이는 우선순위 도구입니다. 최종 판단은 주제 적합성과 제작 자원까지 같이 보셔야 합니다.

데이터는 어디에 저장되나요?

API 키와 즐겨찾기는 브라우저 로컬 저장소에만 남깁니다. 서버로 따로 보내지 않도록 구성했습니다.
